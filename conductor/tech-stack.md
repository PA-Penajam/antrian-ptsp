# Tech Stack

## Backend
- **Language:** PHP 8.x
- **Framework:** Laravel 12.x
- **Database:** SQLite / MySQL / PostgreSQL (Laravel Standard)

## Frontend
- **Framework:** Livewire 4.x

- **CSS Framework:** Tailwind CSS 4.x

## Testing
- **Framework:** PestPHP 4.x
